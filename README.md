# Cloud Video Streaming Platform 🎥

A full-stack cloud-based video streaming platform built using Flask, SQLite, HTML, CSS, and JavaScript. Users can register, upload videos, stream content, and manage their own dashboard.

---

## 🚀 Features

- User Authentication (Login/Register)
- Secure Password Hashing
- Video Upload System
- Video Streaming
- Creator Dashboard
- View Counter System
- Thumbnail Support
- Responsive Modern UI
- SQLite Database Integration
- Flask Backend Routing

---

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask

### Database
- SQLite
